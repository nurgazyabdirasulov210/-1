# Магия рук

Сайт: камера + жесты рук (MediaPipe Hands).

- ☝️ один палец — неоновая линия поверх камеры (фон не затемняется)
- ✊ кулак — рисует звёздочки
- 🖐 раскрытая ладонь — звёзды улетают

Запуск: `python3 -m http.server 8000` и открыть http://localhost:8000 (камера работает на localhost/HTTPS).
