# Магия рук

Статический сайт (HTML + CSS + JS-модуль, без сборки): рисуешь руками в воздухе поверх живого зеркального видео с фронтальной камеры. Видео не затемняется.

| Жест | Что происходит |
|---|---|
| ☝️ Вытянут только указательный палец | За кончиком пальца тянется неоновая линия. Каждая новая линия получает новый цвет |
| ✊ Вторая рука сжата в кулак | Пока кулак сжат, указательный палец первой руки рисует звёзды-созвездие (звезда каждые ~40 px пути) |
| 🖐 Раскрытая ладонь | Все звёзды разлетаются от ладони и гаснут |

Кнопки: «Отменить», «Очистить», «Фото» (сохраняет кадр вместе с эффектами).

Распознавание рук: MediaPipe tasks-vision HandLandmarker (2 руки, режим VIDEO). Библиотека (`lib/`) и модель (`models/hand_landmarker.task`) лежат в репозитории, внешние CDN не нужны. Сначала включается GPU, при ошибке или если он слишком медленный, распознавание переходит на CPU (`?delegate=cpu` включает CPU сразу).

## Запуск

Камера работает только по HTTPS или на `localhost`:

```
python3 -m http.server 8000
```

и открыть http://localhost:8000. На Vercel и любом статическом хостинге сборка не нужна.
