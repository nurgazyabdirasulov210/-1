# Магия рук

Сайт, где рисуешь руками в воздухе поверх изображения с камеры (фон не затемняется).

| Жест | Что происходит |
|---|---|
| ☝️ Указательный палец (одна рука) | Рисует неоновую линию |
| ✊ Вторая рука сжата в кулак | Палец первой руки рисует звёзды-созвездие |
| 🖐 Раскрыть ладонь | Все звёзды улетают |

Кнопки: «Отменить», «Очистить», «Фото».

Распознавание рук — MediaPipe Hand Landmarker. Библиотека (`lib/`) и модель (`models/`) лежат в репозитории, поэтому сайт не зависит от внешних CDN.

## Запуск

Камера работает только по HTTPS или на `localhost`.

```
python3 -m http.server 8000
```

и открыть http://localhost:8000. На Vercel сборка не нужна: это статический сайт.
